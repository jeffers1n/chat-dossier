# Досье переписки

Локальное приложение, которое превращает проектный чат в хронологию решений, обещаний, изменений, открытых вопросов и расхождений. У каждого вывода есть цитата и ссылка на исходное сообщение.

## Запуск

Нужен Python 3.10+. Устанавливать пакеты не требуется.

```sh
python3 app.py
```

Откройте [127.0.0.1:8000](http://127.0.0.1:8000) и нажмите **«Открыть учебное дело»**. Демо полностью вымышленное и работает без API-ключа.

Для анализа своего чата задайте ключ Gemini в терминале и запустите сервер:

```zsh
read -s 'GEMINI_API_KEY?Gemini API key: '; export GEMINI_API_KEY; echo
python3 app.py
```

Загрузите экспорт Telegram в JSON или текстовый файл TXT и нажмите **«Начать расследование»**. По умолчанию используется `gemini-3.6-flash`. Другую модель можно выбрать при запуске, например `LLM_MODEL=gemini-3.5-flash-lite python3 app.py`. Для порта 8001 добавьте `PORT=8001`. После изменения кода сервер нужно перезапустить.

## Что важно знать

- Чат остаётся на вашем компьютере до анализа; при анализе его текст отправляется выбранному API-провайдеру. Само приложение не сохраняет чат на диск.
- Приложение проверяет, что цитаты действительно есть в сообщениях. Смысл выводов всё равно нужно проверять: модель может пропустить решение или ошибиться в интерпретации.
- Длинный чат разбивается на части. Если дополнительная сверка всего чата не проходит из-за лимита API, приложение показывает результаты частей и предупреждает о возможных пропущенных связях.
- Лимиты и стоимость запросов зависят от вашего аккаунта и модели. Личные переписки, ключи и результаты их анализа не следует добавлять в репозиторий.
